تحديث تصنيف أهمية المباني
===========================

المزايا:
- لكل مبنى تصنيف: عادي / حرج.
- الافتراضي للمباني الحالية والجديدة: عادي.
- اختيار التصنيف عند إضافة أو تعديل المبنى.
- فلتر جديد في صفحة المباني: الكل / حرج / عادي.
- المباني الحرجة تظهر أولًا في قائمة المباني.
- شارة حمراء "حرج" على بطاقة المبنى وفي صفحة التفاصيل.

التركيب:
1) شغّل supabase/patch_building_criticality.sql في Supabase SQL Editor.
2) ارفع ملفات الكود إلى GitHub بنفس المسارات.
3) README اختياري ولا يحتاج رفعه.
