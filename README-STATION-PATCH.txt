تحديث المحطات / المواقع + الفلاتر المترابطة

1) شغّل أولًا في Supabase SQL Editor:
   supabase/patch_building_station_filters.sql

2) بعد نجاح SQL ارفع ملفات الكود إلى GitHub بنفس المسارات الموجودة داخل الحزمة.
   ملف SQL لا يحتاج رفعه إلى GitHub للتشغيل، ويمكن حفظه هناك للتوثيق فقط.

النتيجة:
- كل مبنى يصبح مرتبطًا بمحطة/موقع.
- صفحة المباني: فلتر محطة/موقع.
- إضافة/تعديل مبنى: اختيار أو كتابة المحطة/الموقع.
- صفحة المعدات: فلتر محطة ثم فلتر مبنى يتحدث تلقائيًا.
- إضافة/تعديل معدة: اختيار المحطة أولًا ثم تظهر مبانيها فقط.
- المعدة لا تخزن station بشكل مكرر؛ يتم استنتاجها من المبنى لمنع تعارض البيانات.
- عرض المحطة في جدول المعدات وصفحات التفاصيل.

الترحيل التلقائي للسجلات الحالية:
JED -> محطة جدة
47A-B1 / 47-B2 -> محطة العيينة
MUZ -> محطة المزاحمية
QSM -> محطة القصيم
KHF -> محطة الخفجي
باقي المباني -> الحرم الرئيسي

يمكن تعديل أي مبنى لاحقًا وتغيير المحطة من واجهة النظام.
